# KL's Tools — Releases

Built binaries and update feeds for the KL's Tools family, published
here so Sparkle (and anyone with a link) can fetch them over plain
HTTPS without authentication.

**This repo contains no source code, and never will.** Every tool's
actual source lives in its own private repo:

- [LKLicenseKit](https://github.com/kauealemos777/LKLicenseKit)
- [AudioLocalizationToolbox](https://github.com/kauealemos777/AudioLocalizationToolbox) — the Toolbox
- [AudioPreProductionToolkit](https://github.com/kauealemos777/AudioPreProductionToolkit)
- [AudioSYNCTool](https://github.com/kauealemos777/AudioSYNCTool) — Audio Distribution Toolkit
- [TimeConstraintCheckTool](https://github.com/kauealemos777/TimeConstraintCheckTool) — Audio QA Toolkit
- [ASRecValidator](https://github.com/kauealemos777/ASRecValidator) — AS-REC Audio Validator
- [MergeStemsTool](https://github.com/kauealemos777/MergeStemsTool) — EARTH · Merge Stems Tool

## Layout

Each tool gets its own folder here, holding that tool's `appcast.xml`
plus its versioned release archives (generated by that tool's own
`scripts/generate_appcast.sh` / `make_release.sh`):

```
toolbox/appcast.xml
toolbox/KL's Audio Localization Toolbox 0.2.dmg
preproduction-toolkit/appcast.xml
preproduction-toolkit/Audio Pre-production Toolkit 1.0.dmg
...
```

Each tool's `SUFeedURL` points at its own folder's `appcast.xml` via
this repo's raw GitHub URL.
